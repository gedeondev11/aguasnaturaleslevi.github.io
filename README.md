### Objetivo general  

Diseñar una sitio web dinamico para el negocio de aguas naturales.,  Para mostrar  información de las aguas y productos  que se venden en el micro-negocio.

---  

### Objeticvos especificos  

* **Diseñar** un sitio web dinamico para la presentacion del micro-negocio.
* **Generar** opiniones de acuerdo al rellenado de un formulario.  

* **Exportar** precios actuales y totalmente actualizables a medida del tiempo que se den actualizaciones con el precio de productos.

---

### Valor de proyecto

El sitio web dinamico ayudara a potencializar las visitas en google maps y tener una referencia del sitio de venta, ayudando a la visibilidad del micro-negocio.

### Análisis

#### Requisitos funcionales
Se describen los requisitos funcionales para el sitio dinamico del micro-negocio.  

##### **RF01:** Presentación (Inicio)  

* **Nombre:** Inicio.
* **Prioridad:** Alta.  
* **Estado:** Por definir.  
* **Descripción:** 
    * **Entrada:** Mostrar una presentación del micro-negocio, misión, visión, historia.  
    * **Salida:** Los usuarios  
    podrán ver una presentación,  
    corta del micro-negocio y una clara referencia hacia él.

##### **RF02:** Productos

* **Nombre:** Prodcutos.
* **Prioridad:** Alta.
* **Estado:** Por definir.
* **Descripción:**
    * **Entrada:** Crear un apartado para mostrar precios,  
    de aguas naturales, cachuates, pepitas, chicharrones,  
    y otros productos que se ofrerzcan.  
    * **Salida:** El usuario puede ver la promoción de productos que se venden, aguas naturales de diferentes sabores, piña, naranja, melon,cebada, avena, jamaica, y en comestibles, pepita, cacahuate, sunchos, y chicharrones.  

##### **RF03:** Ubicación     

* **Nombre:** Ubicación.
* **Prioridad:** Alta.
* **Estado:** Por definir.
* **Descripción:**
    * **Entrada:** 
        * **Mostrar** google maps para ubicar el punto de venta.
        * **Crear** un formulario de feedback para el sitio.  

##### **RF04:** Feedback y Opiniones

* **Nombre:** Opiniones.
* **Prioridad:** Alta.
* **Estado:** Por definir.
* **Descripción:**
    * **Entrada:** 
        * **Mostrar** en el apartado de ubicación un formulario  
        para recibir opiniones acerca de su compra.
        * **Crear** un formulario de feedback para el sitio (Footer).
